# 常用缩写和快捷键

在报告输入框里输入左侧完整缩写后，会自动出现右侧内容。不需要再按空格、回车或标点。

| 输入什么 | 出现什么 |
| --- | --- |
| `;red` | 插入红色 `（见图）` |
| `;fzg` | 自动读取并填写 SUVmax，后接红色 `（见图）`；没有测量值或读取失败时，光标会停在数值位置供手工填写 |
| `;fwj` | `放射性摄取未见明显增高` 后接红色 `（见图）` |
| `;fjd` | `放射性摄取降低` 后接红色 `（见图）` |
| `;cma` | 自动读取当前图像的 1–3 个尺寸；没有测量值时把光标留在原位置 |
| `;cmx` | `cm×cm`，光标会回到两个数字中间 |

## 全局快捷键

| 按什么 | 做什么 |
| --- | --- |
| Ctrl+Alt+Esc | 暂停或恢复工具。暂停后再按一次可以恢复 |
| Ctrl+Alt+Q | 退出工具，即使工具已经暂停也可以退出 |

以下全局方向键默认关闭；确有需要时请联系维护者协助启用：

| 按什么 | 做什么 |
| --- | --- |
| RAlt+H | 向左 |
| RAlt+J | 向下 |
| RAlt+K | 向上 |
| RAlt+L | 向右 |

启用前请退出原始 `legacy/karabiner.ahk`。清理后的 `medex_legacy_compat.ahk` 已不再注册这四个方向键，可以与麦旋风同时运行。

## 快速标图

在报告编辑器里选中一句文字，按 `Shift+Alt+S`。麦旋风会找到同一 MedEx
进程中结构唯一的报告图像窗口，把文字粘贴到“图像描述”区域，并向下一张图片
滚动一次。目标窗口在主屏或副屏均使用同一套结构和窗口相对算法，不使用旧脚本
的固定屏幕坐标。

动作在 `S` 按下时立即开始。连续标图时可以一直按住 `Shift+Alt`，每按一次
`S` 执行一次；无需在每张图片之间松开两个修饰键。

第一次成功后，caption 会留在剪贴板和当前进程的临时内存中。此时不需要回到
编辑器重新选择文字；保持报告图像窗口在前台，再按 `Shift+Alt+S`，即可把同一句
caption 连续写入下一张图片。需要换一句时，回到编辑器选择新文字后再次触发。

托盘菜单“清除快速标图 caption”可立即结束本轮复用。重新加载或退出麦旋风也会
清除临时 caption。此功能有意不恢复操作前的剪贴板，但每次都会恢复鼠标位置。
未复制到新文字、目标窗口不唯一、窗口结构变化或焦点切换时会停止，不会用旧
caption 猜测执行。

## 阅片工具快捷键

设置窗口的“快捷键”页可以启用以下功能：

| 默认按键 | 做什么 |
| --- | --- |
| Ctrl+Alt+1 | 选择箭头工具 |
| Ctrl+Alt+2 | 选择长度测量工具 |
| Ctrl+Alt+3 | 按下并松开一次，选择 3D SUV 测量工具 |
| Ctrl+Alt+4 | 截图，相当于在阅片窗口按 F12 |
| Ctrl+Alt+5 | 清除阅片窗口里的全部标注 |

这些快捷键默认关闭。只有维护者完成当前工作站验证后才应启用；按键也可以在设置页修改。组合键可以只使用一个 Ctrl、Alt、Shift 或 Win 修饰键。也可以设置单个字母或数字（例如 `S`、`D`）；这种无修饰单键只在 Viewer 位于前台时生效，不会占用报告窗口或其他程序的正常输入。带修饰键的箭头、长度测量、3D SUV 和清除全部标注可在 MedEx 报告窗口或 Viewer 前台使用；截图始终只在 Viewer 前台使用。

启用方法：双击托盘里的麦旋风图标，打开“快捷键”页，勾选需要的功能，再点“保存”。要把 Win 加进组合键，勾选该行右侧的“Win”。保存后麦旋风会重新启动。

完整按下再松开截图组合键后，麦旋风会向阅片窗口发送 F12，整个窗口会快速白闪一下。它只表示按键已经发送，不表示截图已经保存完成。

清除快捷键会调用阅片窗口右键菜单里的“删除全部标注”，整个动作只打开一次菜单。它不会移动鼠标；如果找不到正确的 Viewer、菜单命令或出现需要人工处理的确认窗口，右下角会显示失败提示。

如果按键后选中的工具不对，先按 Ctrl+Alt+Esc 暂停，不要继续重复按，直接叫维护者来看。

如果工具行为异常，先按 Ctrl+Alt+Esc 暂停。

SUVmax 成功写入后，工具会尝试清除阅片窗口里的全部标注。报告已经写入但标注未能清除时，右下角会短暂提示；报告内容不会撤销。

如果 `（见图）` 不是红色，请暂时不要依赖这个快捷输入，并联系维护者。正常情况下，不需要手动从 Word 复制红色文字。
