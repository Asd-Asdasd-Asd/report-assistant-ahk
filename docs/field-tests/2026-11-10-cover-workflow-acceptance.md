## 实现范围与限制

封面图复用 Montage 的布局定位、Tab 点击和受对应 ComboBox 限定的下拉选择。
封面图独立启用，默认关闭，默认 Ctrl+Win+Shift+C；设置位于“其他”页。
配置键复用安全保存事务，位于 `[MontageHotkeys]` 的 `CoverEnabled`、`CoverChord`。
Body/Head/Lung 的行列、层厚、层数、缩放和 null 图注流程不用于封面图。

配置只读取绑定 Viewer 可执行文件目录下 `MultNMSoftInfo/1/MxPetCtTemp.ini`，
要求 ShowModel7 为 page 0 的已验证四窗格 schema（等大四格，类型 1/2/3/1、方向均为 2、
origin 1/1/1/2）。不选择 `1-1920`，不以更新时间推断活动配置，不写 Viewer 配置。
这是显式支持的 profile，不宣称覆盖任意 MedEx 版本、自定义布局或布局面板其他页面。

图像区域从同 PID、同 root owner 的实时窗口中发现；要求只有一个符合尺寸和范围的绘图控件，
并在后续阶段重新检查窗口身份、矩形和点击点命中。下半部两格按此已验证 profile 计算位置，
不复用旧绝对坐标。无法证明目标唯一时停止，不自动重试。

布局面板未暴露当前选中布局/页面信号，采用已验证的 Montage 单次物理选择和 350 ms 等待；
操作者须确认显示模式面板处于已验证页面。Default 通过下拉当前值确认。
保存和层面复位仅有 Invoke 派发证据，分别等待 550/350 ms；没有图片持久化或复位完成的确认信号。
成功提示仅称保存指令已执行。失败可能已有局部副作用，不自动补偿、删除或重做。
封面图与 Montage 互斥；执行期间阻止 Viewer 工具/截图/清除快捷键插入。剪贴板和鼠标在 finally 恢复。

## 操作者验收

1. 使用无患者隐私的测试检查。手工退出旧麦旋风、原始 legacy、compatibility 和诊断脚本；程序不代为结束它们。
2. 启动本分支测试版，在设置“其他”页启用封面图并保存。保持现有用户配置，其余功能按原配置启用。
3. 确认显示模式面板为已验证页面，在 Viewer 前台按 Ctrl+Win+Shift+C，完整松键，等待提示。
4. 检查排版确为第二行第三列对应的四窗格；图注为 Default；报告左图为 MIP，右图为冠状位融合图；没有提交报告。
5. 手工将融合图滚到偏离中心的层面后，再在合适的测试草稿中执行一次，确认恢复默认后右封面能显示大部分身体。
6. 对比 legacy：图注、左右顺序、图像结果相同；鼠标位置和原剪贴板内容恢复。
7. 分别检查 Body/Head/Lung、Viewer 工具快捷键、报告模板和快速标图的正常使用。
8. 若中途停止，先检查草稿是否已保存左图，再决定人工处理；复制结构化诊断，回传停止码，不回传患者信息或报告正文。

请回传：整体是否通过、左右图和图注是否正确、复位层面效果、是否存在切换焦点/保存等待不足。
其他分辨率、缩放、多显示器和工作站配置仍需单独验收。通过后再合并并撤下旧 compatibility 入口。
