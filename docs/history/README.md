# 历史记录

本目录保存已经完成或已被当前实现取代的调查、checkpoint、现场记录、交接说明和历史更新说明。
它们只作为背景证据，不描述当前 production 行为；当前行为以 `src/`、`tests/` 和 `docs/internal/` 为准。

- 2026-07 至 2026-09 的 Viewer / Montage / Caption / Candidate G 调查与迁移记录。
- `update-notes/`：各版本发布时的内部说明；用户可见说明在 `assets/publish/更新说明.md`，开发者记录在 `CHANGELOG.md`。

新增文件时在文件名中带上日期或版本，不在本目录维护任何"当前状态"描述。
