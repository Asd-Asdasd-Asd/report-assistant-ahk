# 2026-07-27 v0.6.2 维护说明

版本：`0.6.2`

## 本 patch 冻结内容

- Viewer 工具按钮以运行时 native command controls、control ID、共同父面板和
  `GA_ROOTOWNER` 解析，不再使用原工作站固定按钮中心或 pitch。
- Measurement target、SUVMax、尺寸和清除链使用 image owner-family 唯一最佳
  规则，并复用 validated client point。
- Viewer 快捷键允许一个 Ctrl、Alt、Shift 或 Win 修饰键；无修饰时仅允许单个
  字母或数字，并通过 `HotIf` 限制为 Viewer 前台。
- 箭头、长度、3D SUV、截图和清除均等待完整按键释放并以 active guard 防止
  keyboard repeat。
- 正式与 checkpoint 构建均输出到仓库同级 `report-assistant-build`；仓库根目录
  只保留正式 `Build EXE.cmd`。

## 已验证

- 多机器 Vendor profile、native control ID 和 HWND 层级只读审计完成。
- 箭头、长度、3D SUV 在现场机器各连续执行 10 次通过。
- 主图区激活后额外同进程顶层窗口不再造成 Viewer target 不唯一。
- 独立「清除全部标注」已在原失败现场通过。
- macOS 完整 Python suite：271 tests。

## 发布后 smoke test

- 在 Viewer 前台分别测试一个单修饰键和一个无修饰字母键。
- 确认无修饰键在报告窗口和其他程序中不被拦截。
- 测试 F12 截图 pulse、Win modifier 保存/重启，以及箭头/长度松键后单次执行。

## 回退边界

如 v0.6.2 新快捷键作用域出现问题，先在设置页关闭对应功能或按
Ctrl+Alt+Esc 暂停。不要恢复固定坐标、固定 pitch 或包含所有同进程窗口的旧
frame 唯一性规则。
