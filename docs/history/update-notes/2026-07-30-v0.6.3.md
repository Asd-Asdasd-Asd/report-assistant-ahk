# 2026-07-30 v0.6.3 维护说明

版本：`0.6.3`

## 本 patch 冻结内容

- 保留严格 config geometry 作为 Viewer 图像目标主路径。
- 主路径无法唯一解析时，以已验证 native tool group 锚定 PID 和
  `GA_ROOTOWNER`，再选择 foreground image 或唯一显著最大的图像 client。
- fallback 明确排除 tool panel、action root、Button、小窗口和多个面积接近
  的大窗口；无法唯一判断时继续 fail closed。
- 正式打包使用 `Package Release.cmd`，只从五个文件白名单生成带版本号的
  ZIP 和 SHA256；diagnostic/checkpoint 不进入发布包。

## 现场证据

- 新正常机器的自动点与手工点均落在真实图像窗口，原 config geometry
  主路径成功。
- 原失败机器的旧 fallback 曾产生 `75×475` 图像矩形并把自动点落到
  `Button`；结构化 image-surface fallback 修复后 Viewer 相关功能通过。
- 两台机器的真实图像窗口均为同一 Viewer PID、共享工具外框
  `GA_ROOTOWNER` 的大尺寸 `#32770` 直接子窗口。

- Python suite：283 tests。
- Release packager 行为测试覆盖五文件白名单、版本命名、CRC/SHA256、
  dirty/未标记拒绝、旧包清理、无关文件保留和失败恢复。

## 发布后 smoke test

- 在正常机器验证主路径没有回归。
- 核对 ZIP 文件名、顶层目录和“关于麦旋风…”均显示 `0.6.3`。
