# 2026-07-31 v0.7.0 维护说明

版本：`0.7.0`

## 本版本内容

- 将 legacy `Shift+Alt+S` 快速标图迁移到 production。
- 首次从报告编辑器 fresh-copy caption，随后允许在绑定的报告图像窗口连续
  复用同一句话；clipboard 有意保留 caption。
- target 使用同 PID、唯一 top-level signature、`图像描述`/`保存` anchors、
  caption Pane 和 image Document 解析，不使用固定屏幕坐标。
- 热键在 `S` key-down 时执行；只等待主键抬起以阻止自动重复，允许保持
  Shift+Alt 并反复按 S。
- 快速标图默认启用 `Shift+Alt+S`，可在设置窗口的“快捷键”页停用或修改；
  释放检测随配置后的主键变化，并参与统一的重复与保留快捷键校验。
- 首次完整 UIA 解析后缓存 target client rect 和 caption/image points；
  稳定窗口走轻量复核，窗口移动或缩放使缓存失效。
- Viewer context-menu transport 支持复用的 hidden dialog，并向自动图像点
  实际命中的 image child 派发右键。

## 验证状态

- 工作机快速标图功能、连续复用和加速后的 key-down 操作已现场验收。
- Python 全量回归在版本提交前通过。
- 发布后继续在多台机器验证快速标图、SUVMax、尺寸和清除全部标注。

## 发布边界

- 本次先提交并发布 `0.7.0`，不创建 tag。
- 多机器验证通过后再创建 `v0.7.0` tag。
