# 2026-08-13 v0.8.0 维护说明

版本：`0.8.0`

## 本版本内容

- 将 Body、Head、Lung Montage 一键排版纳入 production，并由设置管理快捷键、
  布局行列和三个 profile 的数值。
- 对 Montage 中可观察的菜单和控件状态使用有上限轮询，缩短正常快速路径；没有
  可靠完成信号的布局切换仍保留短暂稳定等待。
- Viewer 测量与清除标注共用 context-target session，并在冷启动、窗口世代变化和
  布局改变时重新发现目标。
- 双 PET 对比布局中的自动右键固定在图像区域左半侧，并拒绝不能创建图像菜单的
  Viewer root receiver。
- 快速标图首次 Save 激活增加一次受限重试；只有 Save dispatch 完成后才进入既有
  settle 和下一张动作。
- Viewer 失败日志只记录窗口、候选、缓存、阶段和耗时等诊断元数据，不记录患者
  内容、报告文本或剪贴板内容。

## 验证状态

- macOS 上完整 Python 静态回归和 generated release 一致性检查在发布提交前执行。
- Montage production 一键链此前已在目标工作站通过；本次仍需在 Windows 工作站
  对 `0.8.0` 正式构建做发布 smoke test。
- macOS 静态验证不能证明 Windows UIA、Vendor 时序或最终 Caption 持久化成功。

## 发布边界

- `main` 保存 `0.8.0` source 与可复现 generated release 基线。
- Windows/MedEx 验收和正式 EXE/ZIP 打包按 release checklist 在工作站完成。
- Automation Diagnostics MVP 在后续 `feature/automation-diagnostics` 开发，不混入
  `0.8.0` 发布基线。
