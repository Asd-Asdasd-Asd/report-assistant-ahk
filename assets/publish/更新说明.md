# 麦旋风 v0.6.2 更新说明

## 这版有什么

### v0.6.2 修复和调整

- 修复了不同电脑上阅片工具按钮大小、间距不一样时，快捷键失效或选中相邻工具的问题；
- 修复了外层 Viewer 窗口数量或面板坐标变化时，正确工具按钮仍被误判为布局校验失败的问题；
- 修复了点击主图区后出现多个 Viewer 图像窗口，导致自动获取或「清除全部标注」找不到目标的问题；
- 快捷键现在可以只用一个 Ctrl、Alt、Shift 或 Win 修饰键，例如 Ctrl+S；
- 也可以直接使用单个字母或数字，例如 S、D、1；这种单键只在 Viewer 位于前台时生效，不会影响报告窗口和其他程序；
- 箭头和长度测量会在按键完全松开后只执行一次，长按不会连续触发；
- 清除、SUVMax 和尺寸读取继续在目标不明确时停止，不会猜测图像窗口。

### v0.6.1 新增

- 可以用快捷键选择阅片窗口里的箭头、长度测量和 3D SUV 测量工具；
- 可以把自己习惯的按键映射成阅片窗口的 F12 截图；
- 可以用独立快捷键调用「删除全部标注」；
- 五项功能默认关闭，需要时在设置的「快捷键」页逐项启用；
- 默认按键是 Ctrl+Alt+1、Ctrl+Alt+2、Ctrl+Alt+3、Ctrl+Alt+4、Ctrl+Alt+5，也可以自己修改；
- 每一项都可以另外勾选 Win 键；
- 3D SUV 会在完整快捷键松开后选择一次，之后不需要持续按住；
- 按键不会移动鼠标，也不会把正在写报告的窗口切走。

### v0.6.0 已有

- `;fzg` 会自动读取阅片窗口里标注的 SUVMax，直接填进句子；
- 模板里有「自动获取 SUVMax」和「自动获取尺寸」两个元素，可以制作自己的模板；
- 没有标注或者读取失败时不会填入错误数值，光标会停在该填的位置供手工输入；
- 读取测量值后会自动清除图上的标注，方便继续测量；
- 出现问题时，屏幕右下角会闪出简短提示。

### v0.5.0 已有

- 可以在图形设置窗口里新增、修改、启用、停用和排序文本模板；
- 模板可以插入光标位置、当前日期和红色「（见图）」；
- 旧配置首次启动时会自动备份并升级；
- MedEx 里的红字插入、光标定位和颜色恢复更稳定；
- 缩写只在 MedEx 窗口里生效，退出和紧急停止快捷键仍然全局可用。

## 怎么启用快捷键

1. 双击屏幕右下角的麦旋风图标；
2. 打开「快捷键」页；
3. 勾选要用的功能；
4. 点「保存」。

保存后麦旋风会重新启动。无修饰的单个字母或数字，以及截图按键，只在阅片窗口前台时生效；完整按下再松开截图按键后发送纯 F12，整个阅片窗口会快速白闪一下。这个闪光不代表截图已经保存完成。

如果按键后选中的工具不对，先按 Ctrl+Alt+Esc 暂停，不要连续重复按，直接来找我。

## 怎么升级

1. 先从托盘退出旧版；
2. 用新的完整文件夹替换旧程序文件；
3. 启动新版。

你的个人设置会自动保留，替换程序文件不会丢。
